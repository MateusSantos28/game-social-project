# Jornada DS: EEEP Jaime Alencar — Edição FireRed

Jogo educativo 2D pixel-art inspirado em clássicos de GBA (estilo Pokémon FireRed) para apresentar o curso técnico em Desenvolvimento de Sistemas da EEEP Jaime Alencar de Oliveira aos novos estudantes.

## 🚀 Como executar o projeto

### Pré-requisitos

- [Node.js](https://nodejs.org/) (versão 18 ou superior recomendada)
- npm

### 1. Instalar as dependências

```bash
npm install
```

### 2. Rodar o servidor de desenvolvimento

```bash
npm run dev
```

Após iniciar, abra o link exibido no terminal (geralmente `http://localhost:5173`) no navegador.

### 3. Gerar o build de produção

```bash
npm run build
```

Os arquivos otimizados para produção serão gerados na pasta `dist/`.

### 4. Visualizar o build de produção

```bash
npm run preview
```

### 5. Verificar o código (Lint)

```bash
npm run lint
```
